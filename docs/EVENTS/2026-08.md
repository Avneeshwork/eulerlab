# Events — August 2026

Exchange and regulatory changes that break assumptions, backtests or contract
specs. The automated monitor (NSE + BSE + SEBI circular pages, diffed daily)
is not built yet — it arrives with the data pipeline. **Until then this file is
filled in by hand and is not complete.**

Market-structure changes are also a *strategy idea source*, not just a
maintenance burden: they create mechanically explainable inefficiencies with a
known start date.

## 2026-08-17 — Backlog seeded from the reference playbook

**Source:** `docs/quant_platform_playbook.md` §0.1 and Part III (an
operator-supplied reference document, **not** a primary circular).
**Status:** UNVERIFIED. Tracked as A-002, A-003 and A-005 in
`docs/ASSUMPTIONS.md`. Recorded here because these are exactly the class of
change the monitor will exist to catch, and because each one silently
invalidates historical data.

| Reported change | What it breaks if true |
|---|---|
| Index derivative lot sizes revised repeatedly (Nov 2024, Oct 2025, and again for the Jan 2026 series) | Any backtest with a hardcoded lot size is wrong for part of its own sample. This is why lot size is a time-versioned field in the security master, never a constant |
| Weekly expiries cut to one per exchange — Nifty 50 weekly on Tuesday (NSE), Sensex weekly on Thursday (BSE) | Expiry-cycle strategies must key off a calendar, never a weekday literal |
| Bank Nifty / FinNifty / Midcap Select weeklies discontinued (Nov 2024) | **A backtest of a Bank Nifty weekly strategy on post-2024 data is testing an instrument that does not exist.** The result will look like alpha |
| No calendar-spread margin benefit on expiry day for the expiring leg (since Feb 2025) | A margin model without this rule will get positions squared off by the broker's RMS that the backtest thought were fine |

**Action:** every row above must be confirmed against the primary NSE/BSE/SEBI
circular before it reaches the security master. A-003 is due before Sprint 2
(the recorder's schedule depends on expiry days); A-002 before Sprint 3.

## What the monitor will do, once built

Pull NSE, BSE and SEBI circular listing pages daily, diff against yesterday, and
file anything touching contract specs, lot sizes, expiry changes, margin rules or
new products into `docs/EVENTS/YYYY-MM.md`, flagged in the next sprint review.
Roughly five minutes of compute a day. Scheduled alongside the weekly data
profiler once there is data to profile.
