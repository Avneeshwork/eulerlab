# ADR-127: The engineering agent codes the signals research cards name, free model first, for the operator to merge

- **Context:** The idea lab backtests research cards automatically, but only when every signal a card names is in the feature library; others were skipped every day ("unknown feature 'liquidity_beta'"). The operator asked (2026-11-03) that cards which pass be coded by the engineering agent and backtested, and that the engineering agent can use a free model too.
- **Options:** (a) The model edits `features/library.py`. (b) One new module per signal under `features/coded/`, loaded into `library.BY_NAME`, with a purity check. (c) Let the lab run model-written code without review.
- **Choice:** (b). The lab records unbuildable named signals; the work runner makes a `code_feature` task for complete cards, at most 2 a day; `fixer.code_feature` writes the module and test on `agent-feature/<name>-<id>`, proves it (purity, ruff, mypy, tests, engine self-test), pushes and opens a pull request. The operator merges; the lab's next run tests the card, trials logged first. Models are tried in `options.models` order: Groq (free), then Claude Opus, the next only when the first one's code failed a check or its request does not fit Groq's per-minute limit. The rule "never fix on a weaker model" is replaced by "never keep code that fails a check", for fixes too.
- **Why:** (a) puts every feature at the mercy of one model reply. (c) breaks the lab's rule against running model-written code, and a pure-function check plus review is cheap. A per-file purity check makes look-ahead structurally impossible for a signal of one stock's own history.
- **Cost if wrong:** Only signals of one stock's own price, volume and turnover can be coded; cross-sectional ones (liquidity beta, herding) are reported, not coded. A wrong-but-pure signal passes the checks; the review and the lab's IC screen and gate are the guard. Each merged signal adds trials when tested. Opus requests cost about $0.10 each at $4 / $20 per million tokens (config/llm.yaml, research 129). Live on 2026-11-03: Groq refused `liquidity_beta` correctly (1 request, 3 s) and, once the clean-up steps were in, coded a test card's signal that passed every check (2 requests, 32 s); on another run its test had a type error both tries, which is when Opus is used. Proving the path cost 8 Opus requests, about $0.80.
