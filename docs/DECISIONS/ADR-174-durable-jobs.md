# ADR-174 — A job is a list of kept steps: it resumes where it died, and its budget is checked before each step

**Date:** 2026-11-13. **Status:** accepted for the autopilot; the data agent only leaves dead letters so far. Issue #136 under #134.

- **Context.** The nightly autopilot was one function. Killed halfway it began again from the top: new cards, the same screens, and a gate run that finished but was not yet noted could use two more ledger entries. Budgets were checked by the agent itself.
- **Options.** (a) A workflow service (Temporal, Celery, a queue): a new heavyweight dependency, against cost discipline. (b) Rewrite each job as a state machine. (c) A small step recorder used inside the existing function: `job.do(name, fn)` runs the step and keeps its result, or returns the kept result on a rerun.
- **Choice.** (c). `eulerlab/jobrun.py`. Rows go to `data/jobs/<name>.jsonl`, or Postgres's `append_log` when the database is on, through two new helpers (`db.stream.add_row`, `read_rows`) and one table (`ROW_FILES`) that `make db-import` reads, so a new store needs no importer code. Before a step starts the runner checks the constitution: ledger entries against the week's cap, rupees against the month's AI budget. A step marked `once` that started and never finished is settled by looking (for a gate run: the trial ledger), never by running again blind. A step that fails after its retries goes to a dead-letter list. The autopilot's write, register, each screen, each gate, each paper-book start and the write-up are steps. The data agent leaves a dead letter when a feed re-run fails.
- **Why.** It needs no new service and changes the autopilot's order of work not at all, so its tests pass unchanged. The scheduler from ADR-164 already runs both jobs on a server.
- **Cost if wrong.** A step's result must be JSON; one that is not would come back changed on a rerun, so every result goes through JSON on the first run too. A validation that finished before a kill, with no gate after it, is counted and reported but the card is not gated again without a person. Nothing stops a step that runs too long; seconds are recorded only. "Five sessions on the server with the Mac off" has not been run (T-4585).
