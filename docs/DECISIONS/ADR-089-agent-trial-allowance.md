# ADR-089: The idea lab may spend up to 5 trials a week testing the research agent's drafts

- **Context:** The operator asked for the model to research, bring ideas and backtest them itself, and chose an allowance of 5 trials a week on 2026-10-29. Until then the loop stopped at drafts (ADR-084, `research/orchestrator.py`), because an agent that tests its own ideas is selecting on its own output.
- **Options:** (a) no agent testing; (b) free testing; (c) one narrow path with a weekly allowance, every evaluation logged as a trial.
- **Choice:** (c). `research/agent_trials.py` is the only module that lets an agent spend a trial, and only the idea lab (`agents/workers/lab.py`) may import it (test-enforced). A card is tested only if every trial it needs fits in what is left of the week (IST); its configurations are never cut to fit. Each distinct feature gets an IC screen (one trial); only a card whose every feature passes (IC at least 0.02, t at least 2.0, `config/agent_trials.yaml`) is backtested, one Tier A run per configuration (one trial each). Every trial goes into `data/derived/trials.jsonl` as `agent|<card>|...`, written before the result is read. The panel is cut at the card's holdout first. The skeptic attacks each backtest, and survivors go to the inbox.
- **Why:** The operator gets a loop that finds and tests ideas without being asked. Every test still raises the noise bar for everything, so the bar keeps pricing the search.
- **Cost if wrong:** At 5 trials a week the bar rises, about 260 trials a year at most. Because the lab picks which drafts to test, the selection effect described in `orchestrator.py` is now partly in agent hands; the gate's bar counts the trials but not the choice. Lower `per_week` to slow it; 0 stops it. The lab can only test library features in the shapes `codegen` provides (S-048).
