# ADR-089: Backfill FII/DII cash-flow history by scraping aggregator pages

- **Context:** NSE serves the latest FII/DII day only (research 004), so `make fii-dii` (ADR-088) has no past. On 2026-10-30 the operator asked: "get fii - dii historical data from other place then like money control or other website by scrappping them atleast last 1 year data". All three sites read have terms that forbid this use (research 127). Trendlyne's, read 2026-10-30: "You may not resell, redistribute, broadcast or transfer the information or use the information in a searchable, machine-readable database unless separately and specifically authorized in writing". Groww's bar anyone who would "copy, reproduce, ... enter into a database" its content. StockeZee allows "your own personal use" and bars copying it. Moneycontrol answered 403 and was not tried again.
- **Options:** (a) no history; build it forward from NSE. (b) NSDL's official FPI daily reports: official, but FPI only, no DII, and a different figure (T-4186). (c) Scrape Trendlyne for history, and check it against Groww and stockezee. (d) Ask Trendlyne for written permission first.
- **Choice:** (c), by operator decision. This is the same choice ADR-009 made for Trendlyne on 2026-08-18. `make fii-dii-history MONTHS=12` fetches one Trendlyne page per month and one page each from Groww and stockezee. Each page is landed unedited, with at least 2.5 s between requests. Only Trendlyne's days go into the table, and never a day NSE's own capture already holds.
- **Why:** Trendlyne has gross buy, gross sell and net for both groups, and it keeps an archive. Groww (20 days at 0.01 crore) and stockezee (a year, net only) are there to catch errors. The run keeps ADR-009's limits: one thread, a normal browser User-Agent, one try per page, a stop on 403 or 429, no evasion, no redistribution. The robots.txt files do not block these paths, but that is noted, not taken as permission.
- **Cost if wrong:** If a site blocks us, the history stops at what is already landed. NSE's daily capture carries on, and nothing downstream depends on more history. The terms risk is the operator's, accepted knowingly: the data stays private, for research on the operator's own capital, and is never republished. If Trendlyne's numbers were not NSE's, the cross-checks would show it; on 2026-10-30 they agreed to 0.05 crore.
