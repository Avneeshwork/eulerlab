# ADR-172 — Every screen is recorded with its daily returns; the search's cost is shown on each card

**Date:** 2026-11-13. **Status:** accepted for recording and showing; the figures flag nothing until the operator sets thresholds (T-4574). Issues #137 and #139 (first part) under #134.

- **Context.** The autopilot screens ten rules a night and no ledger counted a screen (#122). No record kept daily returns, so "how many different ideas have been tried" had no answer. The holdout is spent (ADR-143) and the operator made 2026 the forward test.
- **Options.** (a) Count screens in the trial ledger; (b) a separate append-only store with returns, and figures computed from it beside each screen; (c) change the gate to use them now.
- **Choice.** (b). `research/experiments.py`: one line per evaluation in `data/derived/experiments.jsonl` (Postgres's `append_log` when the database is on), daily returns in content-named files. A row that is not the forward test and reads past the constitution's `backtest_end` is refused (`SealedPeriod`). `validation/firewall.py` gives each screen: rules tried, families at 0.7 correlation (the gate's own clustering, S-057), the noise bar, the deflated Sharpe at that many families, and one bit on whether the rule kept half its discovery-period Sharpe on the selection period (a coarse, nudged answer: the reusable holdout, research 189). The autopilot records every screen and gate run and prints the figures in its research note.
- **Why.** The ledger is hash-chained evidence of gate runs and the gate reads its count; adding hundreds of screens would change every strict-mode verdict without the operator deciding it. Showing first lets the thresholds be chosen from real numbers. `gates.py` and `mandate.yaml` are not edited.
- **Cost if wrong.** The figures are information, so a wrong one misleads a reader, not the gate. Both historical periods were read by earlier research, so the selection bit overstates how unseen 2024-2025 is. Only rules screened from now are in the store; the cards screened before are not (T-4576), so "rules tried" starts far below the truth.
