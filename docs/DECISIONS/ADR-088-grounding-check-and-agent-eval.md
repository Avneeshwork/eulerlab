# ADR-088: Code checks every figure a model states, and a test set switches off an agent that makes one up

- **Context:** The operator asked what happens if a model starts hallucinating, then said build the fix. Model text reached the operator in two places unchecked: knowledge answers and the market brief's commentary. Nothing measured accuracy, so a worse model or prompt went unnoticed.
- **Options:** (a) ask the model to re-check itself; (b) code compares every figure with what the model was given, and a fixed test set scores each agent; (c) a second paid model as a judge.
- **Choice:** (b). `agents/grounding.py` requires every number (two digits or more, or with a point, comma or %), id (H-, ADR-, T-, A-, S-) and file path in an answer to appear in the tool results or the brief. Knowledge: one retry naming the unsupported figures, then "not held" with the figures listed; the first answer is kept in the output. Market brief: commentary with an unsupported figure is dropped. Each output records a fingerprint of its prompts. `make agent-eval` scores the skeptic on 10 planted fakes and the knowledge agent on `config/agent_eval/knowledge.yaml`. A figure shown to the operator that no tool returned switches that agent off until the operator switches it back on.
- **Why:** Self-correction without outside evidence does not reliably help (research 126); a check against the evidence does, and costs no model call when the answer is grounded.
- **Cost if wrong:** Single digits are not checked, and a correct figure the model computed (a difference of two returned numbers) is refused as unsupported, so some right answers become "not held". The knowledge test set has 12 cases, not the 50 planned (S-047).
