# ADR-217 — Protected files change only with an Operator-Ack trailer, and a halt stays loud

**Context.** Issue #160. On 2026-11-13 a one-line path refactor in `gates.py` (commit 09a0024) tripped the guardian and halted every agent, the nightly autopilot included, for days (T-4596). The change was caught after it landed, the halt was said once, and nothing on `make health` showed that no agent had run or that the experiment store was empty.
**Options.** (a) Leave it to discipline; (b) a commit-msg hook that refuses a commit to `guardian.PROTECTED` without an `Operator-Ack: <reason>` trailer, with the guardian accepting a change whose last commit carries one; (c) the hook writes an ack file under `data/` that the guardian reads.
**Choice.** (b). `eulerlab.operator_ack` is the hook (`pre-commit` stage `commit-msg`) and the reader: the guardian accepts a changed protected file when the last commit touching it has the trailer and the file on disk is byte-for-byte what that commit left, logs it as `acked_change` and re-baselines that file; any other change still halts. A halt sends a Telegram line when it starts and again at 2 h and 8 h (`guardian.escalate`, the hourly `halt-watch` job, `make agents-halt-watch`). `make health` gains `agents_halt`, `autopilot_rows` (rows within 26 h), `experiments_today` (rows by 21:00 IST) and one line per scheduled agent (last successful run against the watchdog's `expect` hours); something that has never run is not red, as with a job.
**Why.** The ack lives in git history, where it can be audited, and survives worktrees and merges; (c) would split across data folders and leave no record in the commit. The git reads sit outside `agents/` because no agent module may import `subprocess` (`agents/boundaries.py`); the guardian imports this one reviewed, read-only helper. Merges are not checked by the hook: their commits were checked when made, and the hook witness logs `--no-verify`.
**Cost if wrong.** Anything that can commit with the trailer (an agent's fixer, a thread) can change a protected file without a halt: the trailer is a statement, not a signature. The operator sees each one as an `acked_change` line in `make guardian`. The deadlines (2 h, 8 h, 26 h, 21:00) are A-125 and may be noisy at first.
