# ADR-171 — A constitution file for what agents may do, and a hard monthly budget

**Date:** 2026-11-13. **Status:** accepted (operator, 2026-11-13: "take 1 lakh capital and backtest up to 2025 end and take 2026 as forward testing"; "doing anything with live account will not be done by agent"; "monthly ai compute budget is 1k"; "no real money while testing, only I will approve for real money"). Issue #135 under #134.

- **Context.** The limits on agents were spread over fifteen agent YAMLs, `mandate.yaml`, ADR-160 and code constants (the autopilot's paper books were sized at Rs 10 lakh in code). Nothing stopped spending on paid models except each agent's daily request count.
- **Options.** (a) Add the new limits to `mandate.yaml`; (b) keep them per agent; (c) one operator-owned file with capital, periods, budget, caps and a level per action, read through one module.
- **Choice.** (c). `config/constitution.yaml` and `eulerlab/constitution.py`: `load()` gives the numbers, `require(action)` returns or raises `NotAllowed`. The loader refuses a file that gives `live_account` or `edit_gate_or_mandate` any level but `never`, or leverage above 1. The guardian protects the file like the mandate; a file that became protected after a baseline was written joins the baseline instead of tripping a halt. `llm/spend.py` prices each recorded request (Anthropic's page, research 189) and `runtime._model_asker` refuses a paid provider once the IST month's spend reaches the budget (`MonthBudgetSpent`); the autopilot then writes with the free model. The autopilot's gate allowance is the smaller of its own and the constitution's, and its paper books use the constitution's capital.
- **Why.** The mandate is the gate's and stays numbers about evidence; this file is about autonomy. One file means the operator can read every limit on one page and a test can prove an action above its level is refused.
- **Cost if wrong.** A missing or invalid file stops every agent action that asks it (fail closed), so a bad edit costs a night's run, not money. The rupee cost depends on a hand-set exchange rate (A-135) and on the token counts providers report; a request whose usage was never recorded is not counted. The operator's own assistant questions are counted but not refused.
