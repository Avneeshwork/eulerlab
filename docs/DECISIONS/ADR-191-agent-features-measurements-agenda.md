# ADR-191 — Agents define their own signals as checked formulas, measure before they screen, and keep an agenda

**Date:** 2026-11-14. **Status:** accepted; operator's "do this" on 2026-11-14 for issues #163 and #164 and the IC and event-study tools (T-4617). Tested on made-up data only; no real night has run (agents halted, T-4596).

- **Context.** After ADR-190 the autopilot could screen, but only rules built from eleven fixed signals, and it could not measure a signal before making a rule of it. A paper needing any other input was "unbuildable" until an engineer added a field. Each night started cold: nothing held the questions being worked on or what had been learned about them. AlphaAgent (arXiv 2502.16789) and R&D-Agent(Q) (arXiv 2505.15155) both let the agent write factors and keep a record of hypotheses and results across rounds.
- **Options.** (a) Engineers keep adding fields by hand. (b) Agents define features as formulas in language v2, checked by code; measurement and agenda tools on discovery data. (c) Agents write free Python features now.
- **Choice.** (b). `research/feature_registry.py`: a feature is a name plus a formula over language-v2 fields and operators, kept only if it compiles under `lang.check_lookahead`, gives the same values on early sessions when later sessions are cut away (at 50% and 75% of the window), is deterministic, covers 5% of tradable stock-sessions, and its cross-sectional ranks correlate under 0.95 with every field and kept feature (A-147). Kept and refused both append to `data/derived/features.jsonl`; a card stores the expanded formula, never the name. Language v2 gains `open_price`, `close_price` and `traded_value` (raw, S-070). `research/agent_tools.py` adds `language`, `define_feature`, `feature_ic` (rank IC at 1, 5, 20 sessions, open-to-close, net of the day's mean, t-stat on non-overlapping sessions), `event_study` (mean after an event against 50 random draws of as many stock-sessions), `screen_formula`, and the agenda tools. `research/agenda.py`: an append-only event file (`ask`, `finding`, `status`, `next`) folded into questions, least explored first; `make agenda` for the operator. The autopilot's loop prompt starts from the agenda and ends with `record_finding`; it accepts `engine_v2` cards, and the lessons' code checks now read v2 rules.
- **Why.** The agent can now build the input a paper needs, check it is not a copy and not a peek, and see whether it predicts anything before spending a screen, and the next night starts from what this one learned. Every check is code, and every look is an experiment-store row.
- **Cost if wrong.** IC and event-study looks are recorded but carry no daily returns, so they do not raise the firewall's bar the way screens do (S-071): a model could take 16 looks a night to choose what to screen. The cut-away test only catches look-ahead in operators, not in a field's own table, which the data layer's `knowledge_time` must still guarantee. Raw prices are not split-adjusted, so a feature dividing prices across a split is wrong for that stock (the split guard drops those returns, not the feature values). A feature may be defined on 2016-2023 and is then fixed for later tests; the selection year is still unseen.
