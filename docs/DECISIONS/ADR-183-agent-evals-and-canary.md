# ADR-183 — Each role has an eval with held-out cases, and an agent's self-change is kept only by the numbers

**Date:** 2026-11-13. **Status:** accepted; three of five roles have a baseline, two need a model run (T-4595). Issue #149 under #134.

- **Context.** Agent prompts and code change often and nothing measured whether a change helped. Self-improving systems improve fast but can overfit their own benchmark, and research agents leak test data into what they learn from.
- **Options.** (a) An LLM judge over sample outputs. (b) Cases scored by code, a quarter held out where no agent can read them, and a canary before a change is kept.
- **Choice.** (b). `agents/evals.py` with twenty cases per role in `config/agent_eval/` (five held out under `heldout/`): on-call (remedy for a dead letter), red team (look-ahead in a formula), generator (valid and new rule), scout (which paper is testable on Indian data), engineer (fix stays in its files, tests pass). The first three are answered by the role's code here; scout and engineer need a model's answers. A proposed self-change is archived in `data/agents/changes.jsonl`, goes to canary only if it beats the current version on the held-out cases, and is accepted after seven days only if its live share is no worse. A role scoring below its floor (80%, A-142) has its agents switched off. The held-out files are refused by `read_document`, outside the knowledge index, in the guardian's protected list and the engineer's operator-owned list; a test checks all four.
- **Why.** Numbers and ids are checked by code; a model judge would add cost and its own errors. A held-out set an agent cannot see is the only defence against a change tuned to the cases.
- **Cost if wrong.** The code-answered roles score 100% on cases written for their current code, so their baseline proves the harness, not that the roles are good; the cases are the start, to be added to as failures happen. The scout labels come from each paper's `markets` field. No real self-change has run a week of canary yet: the test drives one through with fixed dates.
