# ADR-177 — The search breeds rules from rules: islands, lineages, a bandit, and code as the only judge

**Date:** 2026-11-13. **Status:** accepted; run on made-up data only. The two-week comparison with the autopilot has not started (T-4589). Issue #143 under #134.

- **Context.** The autopilot writes ten rules a night in one shot and learns only from lessons in its prompt. Published systems that evolve candidates, with a model proposing changes and code scoring them, find more (R&D-Agent-Quant, LineageEvo, QuantaAlpha, AlphaAgent; the roadmap document has the sources).
- **Options.** (a) Raise the autopilot's nightly count. (b) Let a model both propose and rank. (c) An evolutionary loop where the model only proposes and code validates, de-duplicates, scores and admits.
- **Choice.** (c). `research/evolve.py`. Eight islands (intraday and swing, by the data a rule reads); half of each night's budget to each side. Thompson sampling (the idea lab's `idea_memory.thompson`) picks the island; an island with 60 tries and nothing admitted is closed. A parent is drawn by rank with a bonus for lineages with few children. A child is a model's proposal for a quarter of draws, otherwise one of eight code changes. Code judges: it must compile in language v2, be new, be clean on the engine's screen, stay under 0.5 correlation with every passed strategy and under 0.7 with every pool member; fitness is net Sharpe less charges for size and likeness. The elite of each island are never dropped. The best admitted rule of each island that did not fail the selection period becomes a card with an `engine_v2` block and joins the autopilot's gate queue, so the week's ledger allowance is unchanged. `make agents-evolve`.
- **Why.** AlphaBench found models poor at ranking; here they never rank. Every candidate is a row in the experiment store with its parents, so the firewall counts the whole search and a night can be replayed (the same day gives the same draws).
- **Cost if wrong.** A card is written after its screen, not before: the search record replaces pre-registration for these cards, and the card says so. The settings are assumptions (A-138). Nothing bounds a rerun of the same night from spending a second budget of candidates. It is not scheduled: `eulerlab/jobs.py` is unchanged until a real-data night has been looked at.
