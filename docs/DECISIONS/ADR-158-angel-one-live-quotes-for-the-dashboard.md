# ADR-158 · Angel One prices the dashboard when Kite has no token

- **Context:** the dashboard's live map and movers asked Kite only, with Yahoo (blocked since 2026-08) behind it. Kite's token dies at 06:00 IST and needs a person at Zerodha's page, so on a day nobody ran `make kite-login` (2026-11-09: last token from 11-06) the dashboard showed end-of-day prices only. Angel One logs itself in by TOTP (ADR-154) but was used by `live_shadow` alone, and its SDK was not installed in the API's environment.
- **Options:** require `make kite-login` every morning; make Angel primary; ask Angel only when Kite has no fresh token or answers nothing.
- **Choice:** Kite first (the venue the paper books are costed against), Angel One second, Yahoo last, in `quotes.live` and `quotes.nse_universe`. A Kite token minted before the last 06:00 IST is not sent at all. Angel tokens come from its public scrip master, read at most once a day into `data/master/angel_nse_tokens.json`; `searchScrip` is used for at most five leftovers because it rate-limits after a handful of calls. The Angel login is reused for four hours in the API process, and an Angel answer for the map is reused for 60 s rather than 15 s. `make install` and `make api` now include the `angel` extra. Each quote carries `source: angel`, and the page says "via Angel One".
- **Why:** it needs nobody at a login page, and it prices the whole universe (2,929 of 2,929 on 2026-11-09) in about 12 s.
- **Cost if wrong:** Angel's last price differs from Kite's by a tick or a second; an Angel rate limit refusal shows as an error on the movers' info line and the map falls back to the settled close.
