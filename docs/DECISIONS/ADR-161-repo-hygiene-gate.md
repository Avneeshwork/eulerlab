# ADR-161: Repo hygiene gate, fast commit hook, hook witness

**Context.** Many agents and Claude threads commit into one shared working tree. The audit of 2026-11-09 found little dead code (2 unused modules, 6 kept alive only by tests, 8 duplicated functions) but a commit hook that ran the whole test suite (several minutes, against other threads' half-done edits), so commits were made with `--no-verify` and nothing recorded it. Nothing stopped new clutter either: two ADRs share 095, two research notes share 024, a stale `pnpm-lock.yaml` and a log file were tracked.

**Options.** (a) A rule in CLAUDE.md only. (b) Block `--no-verify` (impossible; git has no hook for it). (c) Make the commit hook fast enough that nobody skips it, add a ratchet check for new clutter, and log skipped hooks after the fact. (d) Paid or heavy tools (SonarQube, jscpd in CI).

**Choice.** (c). `tools/hygiene.py` fails only on clutter not in `tools/hygiene_baseline.json`. The commit hook runs it with `--staged`, judging only the files being committed, so another thread's half-done work cannot block the commit. The full pytest, and mypy over the whole tree, move to pre-push and `make check`; on commit mypy checks only the staged files (an untracked half-written test from another thread blocked a commit on 2026-11-09). `tools/hook_witness.py` marks the tree in commit-msg (git runs it only when pre-commit passed) and compares it in post-commit (which `--no-verify` cannot skip), logging misses to `data/logs/skipped_hooks.jsonl`.

**Why.** Free, local, about one second, and it cannot go red on old debt, so it will not itself become a reason to skip hooks.

**Cost if wrong.** A commit with a broken test can land; `make check` before merging to main and the pre-push hook catch it one step later. Delete the three hooks and the pre-push stage line to revert.

**Follow-up, same day (operator approved).** Removed 10 functions nothing called (94 lines). Merged 3 duplicate groups: the four screens' identical `main` tail into `screen_common.write_and_print`, the stock screen's fee into `screen_common.intraday_fee`, the panel's cached-day reader into `build_factors.cached_dates`. Saved reports: the latest file is now a hard link to its run (`reports._link_latest`), and the 134 existing copies were relinked, freeing 342 MB. Left on purpose: pydantic validators and HTML-parser hooks (called by their frameworks), the micro-05 signal builders (a frozen strategy's record), `alpaca_feed` (stub S-030, checked by the audit rule), `india_factors` (the only fetcher of the IIMA factor data `fair_value` reads), and the two backtest engines' shared closures (merging them touches both engines; worth its own reviewed change).
