# ADR-118: Patch Next.js to 14.2.35 now; Next 16 is its own task

- **Context:** `npm audit` in `web/` listed 19 vulnerable packages, 1 critical, mostly Next.js 14.2.5 (T-4362). Every Next.js advisory that 14.2.35 leaves open is fixed only in 15.5.x or 16.x, and the SVG one only from 16.4.1. Next 16 needs React 19 (RESEARCH/140).
- **Options:** (a) Next 14.2.35, same major, plus `npm audit fix` without `--force`. (b) Next 16 and React 19 now. (c) Change nothing.
- **Choice:** (a). `next` 14.2.5 → 14.2.35 (still pinned exact), `eslint-config-next` ^14.2.5 → ^14.2.35, and `source-map-js` fixed. Next.js advisories drop from 37 to 25, criticals from 4 to 3.
- **Why:** It is a patch release on the same major, and typecheck, lint and a production build pass unchanged. The three critical advisories left need `sharp` (not installed here) or a Windows host (this is a Mac). Next 16 changes the framework under every screen while the UI revamp (T-4283) is in flight on its own branch.
- **Cost if wrong:** If `sharp` is installed later, or the workbench moves to Linux or Windows, the image-optimizer remote code execution advisories apply and the Next 16 upgrade (T-4382) becomes urgent. The high advisories left open (Server Component DoS, rewrite SSRF) were not tested against this app's single fixed rewrite.
