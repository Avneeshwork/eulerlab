# ADR-203 — Portfolio cards through the gate, from 2005, with DP charges

**Context.** Operator, 2026-11-15: "test these for old data also and pass through gate" — Stocks on the Move, Weinstein Stage 2, volatility-targeted NIFTYBEES (`backtest/evidence_daily`). They were screening runs only (no card, no evidence pack), on the main panel from 2015, with no DP charge (HISTORY #94).
**Options.** (a) Give `validation/run.py`'s CPCV path a portfolio shape (dozens of full engine runs per card, hours each); (b) one engine run per card turned into daily `BookDay`s for the intraday battery (ADR-139), which already does CPCV, stress and the gate on daily returns; (c) leave them ungated.
**Choice.** (b). A card whose first configuration is `shape: portfolio_strategy` names an `evidence_daily` strategy; `validation.intraday` runs it on `features.panel.read_panel_with_history(2002-01-01)` (the 2000-2014 file joined by ISIN, mask applied, trimmed to symbols ever in the 800 most traded on a day), trading from 2005-01-01, rows cut before the card's holdout. `costs.router.dp_charges()` adds ₹23.60 per delivery sell inside the run (A-156).
**Why.** Same battery and gate as every other card, one engine run each, and paper/live loads nothing new.
**Cost if wrong.** CPCV paths are slices of one run, not refits, so a rule's state carries across path boundaries (it has no fitted parameters, so this is the only effect). The trim could drop a stock the 250 universe would pick if its turnover never ranked in the top 800 on any day; unlikely, not proved. DP is charged per sell fill, not per scrip-day.
