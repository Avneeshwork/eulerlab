# ADR-084: A paper-reading agent that drafts cards and stops for the operator

- **Context:** The operator asked for a research agent that finds market papers, drafts strategy cards in this repository's format, and stops for human approval before any backtest or trial-ledger entry. They also asked for a stronger free model with a better daily limit (research 123). `make scout` already prices a search and writes cards, but a person has to supply each source by hand.
- **Options:** (a) extend `scout` to search; (b) a separate agent that writes straight into `hypotheses/` with `status: draft`; (c) a separate agent that stages drafts outside everything the gate and the library read, plus an approval command that only moves files.
- **Choice:** (c). `make paper-agent TOPIC=...` prices the search (`budget.price_search`), searches arXiv and OpenAlex (research 124), skips papers already in the library or already staged, reads arXiv HTML or the abstract, and asks the `research_agent` model (Groq `openai/gpt-oss-120b`, falling back to the assistant's OpenRouter ZDR model) for a library entry and a card. Drafts are checked by `library.Paper`, `card.validate` and `critic.review`, then written to `research/agent_drafts/<run>/<paper>/`, which is gitignored. `make paper-agent-approve DRAFT=...` takes the next `H-NNNN`, writes the card as `status: draft` through `card.write`, which never overwrites, and links the paper. Nothing else happens.
- **Why:** (b) would put unread drafts next to registered cards and spend an id on each one. A staging folder keeps the gate's inputs operator-authored. Link, authors, year, card id and holdout date are set by code; the model only writes the wording, and a URL in its reply is dropped. A test reads the agent's imports and fails if it ever imports the backtester, validation, the gate, the OMS or the trial log. Another runs a whole draft and approval with the ledger's `append` set to raise an error.
- **Cost if wrong:** The model can still misread a paper. Every draft carries a red flag saying it was drafted by the agent and not yet read by the operator, and the critic still runs. Free model limits change (A-019): when Groq's key is missing the run says so and uses OpenRouter, which allows 50 requests a day, or 1,000 with a one-time $10 credit.
