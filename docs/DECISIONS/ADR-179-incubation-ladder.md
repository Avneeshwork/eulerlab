# ADR-179 — A ladder moves a gated strategy up on evidence and ends at a list, never at real money

**Date:** 2026-11-13. **Status:** accepted; run on made-up strategies only (T-4591). Issue #146 under #134.

- **Context.** A strategy that passed the gate waited for the operator to start a paper book, and nothing took a book away when it went wrong except the fixed loss limits. The operator's decision is that agents never act on the live account and real money is approved by him separately, each time.
- **Options.** (a) Keep every move manual. (b) A ladder that also sizes a first small live position. (c) A ladder with no real-money rung: registered, paper, paper on live prices, then a list the operator reads.
- **Choice.** (c). `deploy/ladder.py`: each rung's entry test is written in the module before any strategy reaches it. Paper starts at the constitution's test capital. Five clean sessions move a book to live-price paper, where `live_shadow` prices it each morning. The 2026 forward test is scored once by the mandate's `forward_test` rule and kept as the one `forward` row in the experiment store; a fail is final. Decay, a tripped loss limit or a guardian hold moves a book down one rung. Every move is a row in `data/derived/ladder.jsonl` and a line in the inbox. `constitution.refuse_agents` makes `live_money.arm`, the broker login and the order send raise inside any agent's run, and a test checks no agent-side module imports the live order path.
- **Why.** The operator's rule is absolute, so the ladder has no code that could break it, and the guard sits in the live path itself where a later agent cannot route round it. Writing the tests first stops a rung's bar being moved to fit a strategy.
- **Cost if wrong.** Five sessions is the thread's number (A-140); it proves the book runs, not that it earns. The guard reads the agent run from the calling thread, so agent code that starts its own thread would not be seen; the import test is the second lock. The ladder runs at the close on the Mac and has not moved a real strategy yet (T-4591).
